StreamClipper

A personal tool that cuts highlights from my own game streams and publishes them to my own accounts.

What it does

  • Reads a stream recording stored on my own computer
  • Finds loud moments, transcribes the speech around them, and picks the ones worth clipping
  • Renders short vertical clips and writes titles, descriptions and tags
  • Sends the clips to me in Telegram for review
  • Uploads a clip to my own YouTube or TikTok account when I press a button

Who it is for

Only for me, the channel owner. The tool is not offered to other users, has no sign-up, and processes no one else's content or accounts.

How TikTok is used

The tool uses the TikTok Content Posting API for a single purpose: uploading a video file I created to my own TikTok account, with a caption I have seen and approved. Nothing is read from TikTok, nothing is posted automatically without my explicit action.
